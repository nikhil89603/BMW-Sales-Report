# BMW Sales & Pricing Dashboard

An interactive Excel dashboard designed to analyze BMW car sales and pricing data.

## Features

* Total Cars KPI
* Total Sales KPI
* Highest Price KPI
* Average Price KPI
* Month-wise Sales
* Sales by Color
* Sales by Car Type
* Sales by Fuel Type
* Top 10 Model Sales
* Interactive slicers for filtering the dashboard

## Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts
* Slicers
* Data Analysis

## Project Preview

The dashboard provides an interactive visual overview of BMW sales and pricing data, allowing users to filter and explore different aspects of the dataset.
